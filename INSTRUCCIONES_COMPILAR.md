# Compilar en GitHub (sin instalar nada en tu PC)

1. Copia el contenido de este ZIP dentro de la carpeta local del repositorio (reemplazando lo anterior).
2. En GitHub Desktop: Commit to main y Push origin. La compilación empieza sola.
3. En Actions, cuando salga el check verde, descarga el artefacto BATMAN-Mobile-Android-APK.
4. Si falla: abre el paso rojo. El paso "Analyze" lista los errores exactos con archivo y línea.

La app es de depuración (pruebas). Para Play Store hace falta firmarla.
